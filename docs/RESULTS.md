158 条原始验证记录。**

以下比较使用同一组冻结的 UHF/HFCT 分支：等权为 logits 等权融合，门控为分类门控（`gate_ce_logits`）。

## 仅 UHF 污染：−5、0、+5 dB

| SNR | 等权 | 门控 | 差值 |
| --- | ---: | ---: | ---: |
| −5 dB | 96.20% | **98.10%** | +1.90 个百分点 |
| 0 dB | 98.10% | 98.10% | 持平 |
| +5 dB | 94.94% | **96.84%** | +1.90 个百分点 |

在这三个已测 SNR 点，门控相较等权取得两次提升、一次持平。
